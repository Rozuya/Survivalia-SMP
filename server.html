GUIDE RAPIDE

Mods & commandes utiles.

Les commandes et touches ci-dessous sont des repères pratiques. Les touches peuvent être modifiées dans les contrôles Minecraft/mods.

🪦01

AxGraves

Retrouvez et gérez vos tombes après une mort.

COMMANDE/graves
🎙️02

Simple Voice Chat

Discutez vocalement directement dans Minecraft.

RACCOURCI / COMMANDEVou/voicechat
La touche V peut être configurée dans les contrôles.
🌳03

Tree Harvester

Coupez un arbre plus rapidement grâce à la récolte groupée.

UTILISATIONCoupez le tronc comme d'habitude
Le fonctionnement exact dépend de la configuration du mod.
🎒04

Simple Backpacks

Ajoutez du stockage portable à votre aventure.

UTILISATIONOuvrez votre backpack via son raccourci
Le raccourci peut être modifié dans Options → Contrôles.
🧭05

Xaero's Minimap

Gardez une minicarte et vos repères pendant vos explorations.

RACCOURCISBouU
Les touches exactes peuvent être modifiées dans les contrôles de Xaero's.
