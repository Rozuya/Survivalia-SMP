# Survivalia SMP — Site web

Site multi-pages responsive prêt à personnaliser.

## Fichiers
- `index.html` : accueil
- `server.html` : serveur, Terralith et fonctionnalités
- `join.html` : guide pour rejoindre le serveur
- `styles.css` : thème sombre / vert forêt
- `script.js` : menu mobile + copie de l'adresse IP
- `assets/survivalia-smp.jpg` : image fournie utilisée comme bannière

## Personnaliser le logo
Le site utilise actuellement la bannière fournie comme image temporaire dans le header.
Pour utiliser votre logo officiel séparé :
1. Ajoutez par exemple `assets/logo-survivalia.png`.
2. Dans les 3 fichiers HTML, remplacez :
   `src="assets/survivalia-smp.jpg"`
   par :
   `src="assets/logo-survivalia.png"`
3. Vous pouvez conserver `assets/survivalia-smp.jpg` pour la grande bannière de l'accueil.

## Ajouter le Discord
Recherchez les commentaires `DISCORD` dans les fichiers HTML et remplacez `href="#"` par votre véritable invitation Discord.
